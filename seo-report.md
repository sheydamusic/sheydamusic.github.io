# SEO report — sheyda-music-site (English)

Date: 3 November 2026

## Keywords chosen
An artist site mostly ranks for the artist's **name and song titles**, so those come first, followed by natural descriptive phrases:

- Sheyda / Sheyda singer / Sheyda music
- Sheyda Fallen Crown · Chosen One instrumental · Mascara
- singer-songwriter and composer
- classically trained singer
- cinematic neoclassical (instrumental / piano) music
- dreamy indie songs
- booking / licensing (contact section)

Note: there is no free tool for exact search volumes; Google Search Console (you already verified the site) will show which searches bring visitors after a few weeks.
